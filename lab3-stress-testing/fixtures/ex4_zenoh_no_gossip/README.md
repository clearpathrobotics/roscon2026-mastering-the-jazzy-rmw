# Exercise 4 A/B fixture: gossip disabled

Identical to the routed topology's default N=3 Zenoh config
(`docker/rmw_configuration/routed/zenoh/`, generated by `gen_topology.sh`),
except every router (`mock-robot-*-router.json5`) and the observer
(`observer.json5`) has `scouting.gossip.enabled` set to `false` instead of
`true`. Multicast was already disabled in both by the generator; gossip is
the only variable this fixture isolates.

Use with:

```bash
scripts/workshop -t routed up 3 zenoh --rmw-directory lab3-stress-testing/fixtures/ex4_zenoh_no_gossip
```

Regenerate from a fresh baseline if `gen_topology.sh`'s routed+zenoh templates
change:

```bash
scripts/gen_topology.sh routed 3 zenoh
cp docker/rmw_configuration/routed/zenoh/*.json5 lab3-stress-testing/fixtures/ex4_zenoh_no_gossip/
sed -i 's/gossip: { enabled: true,/gossip: { enabled: false,/' lab3-stress-testing/fixtures/ex4_zenoh_no_gossip/mock-robot-*-router.json5
sed -i '/gossip: {/{n;s/enabled: true,/enabled: false,/}' lab3-stress-testing/fixtures/ex4_zenoh_no_gossip/observer.json5
```
